# DESIGN.md — 视觉与交互设计系统

> 设计目标：日系唯美 + 轻赛博，白昼「樱花纸」与星夜「深空」两套主题共用一套结构。视觉服务于阅读，动效服务于定位，不做炫技。

---

## 1. 设计语言

- **关键词**：柔光、纸感、星尘、樱色、玻璃、细线。
- **三条约束**：
  1. 正文区域永远不叠动画层，背景只存在于内容之下（z-index 分层）。
  2. 颜色只从 CSS 变量取，两套主题各一份，不在组件里写死 hex。
  3. 任何动效都必须能在 `prefers-reduced-motion` 下退化为静态。

### 2.3 语义色

`--ok #79C99B`、`--warn #E8B96A`、`--danger #E87A7A`，仅用于状态徽章，不用于正文。

### 2.4 对比度规则

- 正文 ≥ 7:1，次要文字 ≥ 4.5:1，交互元素 ≥ 3:1（图形）且 ≥ 4.5:1（文字）。
- `--sakura` 是高亮装饰色，**不得**作为正文或小字号链接色；正文链接用 `--sakura-deep`。
- 主题切换时不做颜色过渡动画超过 200ms，避免闪烁。

## 3. 字体与排版

| 用途 | 字体 | 说明 |
|---|---|---|
| 标题 | **Noto Serif SC** 600/700 | OFL，自托管 woff2，只 preload 一个字重 |
| 正文 | 系统栈优先：`PingFang SC, Hiragino Sans GB, Microsoft YaHei, Noto Sans SC` | 避免整包中文字体（3 MB+） |
| 等宽 | **JetBrains Mono**（Fuwari 已带） | 代码块 |
| 装饰（可选） | **LXGW WenKai 霞鹜文楷**（OFL） | 仅引用块/签名，不用于长文正文 |

字号阶梯（rem）：`0.75 / 0.875 / 1 / 1.125 / 1.375 / 1.75 / 2.25 / clamp(2.5, 5vw, 3.5)`。

正文：17px，行高 1.9，最大宽度 42em；移动端 16px / 1.85。中文段落首行不缩进，段间距 1.1em。

标题：`h1` clamp，`h2` 1.75rem + 上下 2rem，`h3` 1.375rem。标题可加一条 3px 樱色左标记（`border-left`），仅视觉，`aria-hidden`。

## 4. 间距、圆角、阴影、玻璃

- 间距基数 4px：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`。
- 圆角：`--r-sm 8px`、`--r-md 14px`、`--r-lg 20px`、`--r-full 999px`。
- 阴影（昼）：`0 1px 2px rgba(42,39,51,.04), 0 8px 24px rgba(42,39,51,.06)`；夜：`0 8px 28px rgba(0,0,0,.45)`。
- 玻璃：`background: var(--surface); backdrop-filter: blur(12px) saturate(1.1)`；**只用于导航、卡片、面板**，正文不用；`backdrop-filter` 在低端设备关闭（降级为实心 surface）。

## 6. 组件规范

| 组件 | 规格 |
|---|---|
| Button | 三种：primary（渐变樱→紫，白字，对比度需复核）、ghost（描边 + 玻璃）、icon（40×40）。高度 40/44，圆角 `--r-full`，hover 抬升 1px，active 回压，focus 2px 焦点环 |
| Card | 玻璃底 + 1px 描边 + 20px 圆角；hover 抬升 2px、描边转樱色 30%；`prefers-reduced-motion` 下只变描边 |
| PostCard | 封面 16:9（`aspect-ratio`），标题 2 行截断，摘要 2 行，底部标签 + 日期；整卡可点击但保留标题内链（键盘可达） |
| Chip | 24px 高，圆角 full，淡底 + 细边；用于标签/分类/技术栈 |
| SectionHeader | 左侧 4px 樱色竖线 + 标题 + 右侧「查看全部」文本链接 |
| Avatar | 圆形，96（hero）/ 64（友链）/ 28（导航）三档；`loading=lazy` |
| GlassPanel | 导航、搜索、设置共用；移动端全宽抽屉 |
| TOC | 右栏 sticky，最大高 70vh 可滚；当前项樱色左条；移动端折叠进「目录」按钮 |
| ProgressBar | 顶部 2px，樱→紫渐变，`transform: scaleX()`，`aria-hidden` |
| Pagination | 数字 + 前后箭头，当前页实心，禁用态降透明度 |

装饰元素：星点分隔线（3 个小圆点）、樱花花瓣 SVG（仅在页脚与 404）、噪点纹理（3% 透明度，可选关闭）。

## 7. 动效规则

| Token | 值 | 用途 |
|---|---|---|
| `--dur-fast` | 120ms | hover、焦点 |
| `--dur-base` | 200ms | 面板、卡片 |
| `--dur-slow` | 320ms | 页面淡入、抽屉 |
| `--dur-hero` | 700ms | 首屏入场（只一次） |
| `--ease-out` | `cubic-bezier(.22,1,.36,1)` | 默认 |
| `--ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | 卡片 hover（仅桌面） |

规则：
1. 同一屏同时运行的入场动画 ≤ 2 组；其余用 IntersectionObserver 分批。
2. 入场位移 ≤ 24px，透明度 0→1，时长 ≤ 320ms。
3. 页面转场 180ms 淡出 + 180ms 淡入，不做位移（避免 Swup 容器跳动）。
4. 无限动画只允许「星点闪烁」与「花瓣飘落」，且必须在页面隐藏时暂停。
5. 鼠标特效只在 `(hover: hover) and (pointer: fine)` 下启用。
6. `prefers-reduced-motion: reduce` → 所有位移/缩放/视差关闭，只保留 120ms 透明度变化。

## 8. 页面设计

### 8.1 首页 `/`

- **Hero**：全宽 82vh（移动 70vh），底色渐变 + 星空 Canvas；左侧玻璃卡（最大 560px）：头像 96、站点名、一句话介绍、三个按钮（读文章 / 关于我 / 搜索）。右侧留白给樱花与光晕。滚动提示在底部中央，CSS 呼吸动画。
- **精选文章**：SectionHeader + 3 张 PostCard（≥1024 三列，768 两列，移动单列）。
- **项目**：2–3 张项目卡，含状态徽章与技术 Chips。
- **时间线**：最近 5 条（文章/项目/实验混合），左侧竖线 + 圆点。
- **社交入口**：图标行，`aria-label` 完整。
- **动效**：hero 入场 WAAPI 一次；其余 IntersectionObserver 渐入；3D 星球可选（默认关）。

### 8.2 文章列表 `/posts`（含分类/标签）

- 顶部标题 + 总数；筛选 Chips 一行（分类、标签），可横滑。
- 网格 2 列（≥768），单列移动；每页 8 篇；分页数字。
- 无结果：插画式空状态 + 清除筛选。
- 动效：卡片 stagger 60ms，最多 8 个。

### 8.3 文章详情 `/posts/<slug>/`

- 封面 21:9，视差 ≤ 8px（只 transform）。
- 标题区：标题、日期、阅读时长、标签；底部细线。
- 正文 42em，右侧 TOC 17rem（≥1280 显示）；顶部进度条。
- 代码块沿用 Expressive Code，只换配色变量；公式沿用 KaTeX。
- 文末：上下篇卡片、许可证、回到顶部。
- 动效：仅渐入 + 进度条；不做背景 Canvas 覆盖正文。

### 8.4 归档 `/archive`

- 年份标题吸顶（移动端不吸）；时间线竖线 + 月份圆点；每行：日期、标题、分类。
- 动效：整组渐入一次，不做逐项 stagger（列表可能很长）。

### 8.5 项目 `/projects`

- 卡片网格 2 列；状态徽章（进行中/已完成/暂停）；技术 Chips；外链图标。
- 详情可用 Content Collection 的 `spec` 页承载，不强制独立路由。

### 8.6 关于 `/about`

- 顶部：头像 + 名字 + 一句话 + 社交。
- 正文：自我介绍、技能 Chips（不造假数据、不做百分比进度条）、经历时间线、兴趣标签。
- 动效：仅渐入。

### 8.7 友链 `/friends`

- 卡片网格，头像 64、名称、一句话、域名；hover 抬升。
- 顶部说明「互换友链的方式」，不做自动抓取。

### 8.8 搜索 `/search`

- Pagefind UI 重绘：输入框玻璃底、结果卡片化、关键词高亮用樱色。
- `/` 快捷键聚焦；Esc 清空；空结果显示推荐标签。
- 无 JS 时显示提示「搜索需要 JavaScript」并提供归档链接。

### 8.9 404

- 居中构图：CSS 绘制的角色剪影/星轨 + 「这颗星球上没有这个页面」+ 三个入口（首页/归档/搜索）。
- 鼠标视差 ≤ 12px；reduced-motion 下静止；不加载 Three/Live2D。

### 8.10 笔记 `/notes`、实验 `/lab`、现在 `/now`

- 笔记：按日期倒序的短条目列表，标签过滤。
- 实验：工具卡片网格；端口排查单保留为独立静态页，交互脚本原样迁移。
- 现在：单页 Markdown（`spec` 集合），带「最后更新」时间。

## 9. Live2D 布局与避让

- 位置：右下角，`right: 24px; bottom: 16px`；宽度 `clamp(160px, 20vw, 300px)`。
- 显示条件：`min-width: 1024px` 且 `effectsConfig.live2d.enabled`；移动端折叠为 44px 圆形按钮。
- 避让：
  - 导航栏在顶部，固定高度 64px，模型 `top` 不得进入其下方 64px；
  - 目录在正文右栏内部（不贴视口右边），≥1280 时不重叠；1024–1280 时模型左移至 `right: 48px`；
  - 搜索/设置面板打开时（`body.panel-open`）模型透明度 0.4 且 `pointer-events: none`；
  - 灯箱打开时完全隐藏。
- 交互：点击切动作、鼠标视线跟随、预设台词气泡（最多 12 字，2.8s 自动消失）、拖拽只在「把手」区域（避免误触）、隐藏状态持久化 `localStorage`。
- 无障碍：容器 `role="complementary"`、`aria-label="看板娘"`；关闭按钮 44×44、可聚焦；Esc 隐藏；不进入 tab 序的装饰部分 `aria-hidden`。
- 无模型回退：静态立绘 + CSS 呼吸，按钮与台词仍可用。

## 10. 响应式

| 断点 | 变化 |
|---|---|
| < 640 | 单列；导航折叠为图标 + 抽屉；hero 70vh；关闭鼠标特效与 Live2D；TOC 折叠 |
| 640–767 | 文章卡单列；按钮全宽 |
| 768–1023 | 文章卡两列；侧栏隐藏；Live2D 隐藏 |
| 1024–1279 | 两栏（内容 + 侧栏）；Live2D 显示 |
| ≥1280 | 三栏（导航侧栏 + 内容 + TOC）；Live2D 右下 |
| ≥1536 | 内容最大宽度 1200px，留白增加 |

## 11. 无障碍

- 跳过导航链接（首个可聚焦元素）。
- 语义 landmarks：`header/nav/main/aside/footer`。
- 焦点可见：2px 环 + 2px 偏移，颜色 `--sakura-deep`，任何组件不得 `outline: none` 而不给替代。
- 动画：`prefers-reduced-motion` 全静；`prefers-contrast: more` 提高描边与文字对比。
- 图片：内容图必须有 alt；装饰图 `alt=""` + `aria-hidden`。
- 键盘：TOC、搜索、灯箱、Live2D 关闭均可键盘操作；Esc 关闭浮层。
- 阅读：正文不被固定元素遮挡；锚点跳转留 80px 顶部偏移。
- 语言：`<html lang="zh-CN">`，混排英文保留 `lang` 属性可选。

## 12. 视觉验收清单

- [ ] 两套主题下正文对比度 ≥ 7:1（用工具实测，不靠肉眼）。
- [ ] 首屏无布局跳动（CLS < 0.05）。
- [ ] reduced-motion 下无位移、无视差、无自动播放。
- [ ] 移动端无横向滚动，触控目标 ≥ 44×44。
- [ ] 404/搜索空态/文章空态三种「空」都有设计，不出现裸文字。
- [ ] Live2D 与导航、TOC、搜索面板无重叠（1024/1280/1536 三档截图验证）。
- [ ] 所有动效可在 `effectsConfig` 单独关闭，关闭后页面仍完整可读。
